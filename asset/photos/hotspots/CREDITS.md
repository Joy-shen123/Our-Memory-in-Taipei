# Photographs of the real places — credits

Issue #17. The eight photographs behind the street markers (`photos.js`), each used under its own licence, read on the item's own page (`research/photos/README.md` has the full research, including what was found and rejected). Every file is resized to at most 1200 px on its long edge and re-encoded as webp for the screen; nothing else is altered except the 1961 frame, which is cropped to the photograph from the newspaper page. The page fetches only these files; nothing is hotlinked.
