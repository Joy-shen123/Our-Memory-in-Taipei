## Anchors with nothing found

- **`lux` 樂聲戲院** — No still photograph turned up anywhere searched (memory.culture.tw/tcmb, Taiwan Memory, Wikimedia Commons, 國家攝影文化中心, general web search for the 英雄本色 1986 / 倩女幽魂 1987 billboard years). The only period item found was a 1964 opening-day film clip at [tcmb.culture.tw](https://tcmb.culture.tw/zh-tw/detail?indexCode=Culture_Media&id=702804) (National Film and Audiovisual Culture Center) — it is video, not a photo, and licensed **CC BY-NC 3.0 TW**, which is outside the brief's four accepted tiers (NonCommercial excluded).
- **`ximen-zone` 西門町徒步區** — No item page found with a verifiable open licence for the 1999 pedestrian-zone/arch era. travel.taipei's site-wide terms read CC-BY-like but explicitly carve out some images requiring separate consent, and no specific 1999–2000 item page could be checked against that carve-out. tcmb.culture.tw searches returned several 404'd detail pages; Wikimedia Commons' Ximen Station/Ximending categories only had modern (2008+) or pre-1945 colonial-era photos.
