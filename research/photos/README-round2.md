# Photo research — issue #20 (round 2)

Round 1 (`README.md`) cleared `redhouse`, `dihua` and `temple` on CC0 tcmb.culture.tw colour-survey photographs by 吳宇凡. Each one turned out to have a physical colour-swatch card composited into the frame — round 1 didn't catch it because none of the WebFetch summaries mentioned an overlay. CJ flagged it from a screenshot 2026-09-24: 「有的照片會出現這個色卡」. All three are replaced below, same filenames, no swatch, warmer and busier per CJ's 「剩下照片有點太老有點crippy要拿溫馨熱鬧的照片」.

Every licence below was read on the item's own Wikimedia Commons file page.
